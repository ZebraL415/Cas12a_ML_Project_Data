# EasyDesign Evaluation Outputs

This directory stores collaborator and reference evaluation artifacts. It contains neither experimental labels nor default training inputs.

- `xu_first_run/`: first-run feature importance supplied by Xu.
- `reference_improved_feature_run/`: user-designated improved reference outputs, including importance, row predictions, metrics, and figures.

Evaluation performance becomes project-confirmed only after the generating code, split, parameters, and random seed are reproduced together.
